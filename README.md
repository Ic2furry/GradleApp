<h1>Minecraft Gradle Builder</h1>  

<h2>Небольшое настольное приложение (Tkinter) для упрощённой сборки Minecraft-модов через Gradle. Позволяет выбирать JDK из встроенной папки, запускать gradlew/gradle с настраиваемыми аргументами и просматривать лог сборки в реальном времени. Поддержка светлой и тёмной темы; настройки сохраняются в config.json.
Функции. </h2>  
<div> 
Выбор Gradle-проекта и JDK (скопировать JDK в ./java).<br>
Запуск задач Gradle (набор предустановленных задач + свои аргументы).<br>
Установка JAVA_HOME и аргументов Java для процесса сборки.<br>
Просмотр и очистка логов в реальном времени.<br>
Переключение темы интерфейса.<br>
Сохранение настроек в config.json.<br>
Требования<br>
Python 3.8+<br>
Tkinter<br>
Gradle или gradlew в проекте<br>
JDK (можно скопировать в папку java/ проекта)<br>
<h3>Быстрый старт<br></h3>
1.	Поместить JDK(и) в папку java/ или добавить через интерфейс.<br>
2.	Запустить: python builder.py<br>
3.	Выбрать папку проекта, JDK, задать задачу и нажать "СБОРКА".<br>
Конфигурация<br>
•	config.json создаётся автоматически и хранит: project, java (путь), task, extra_args, java_args, theme.</div><br>

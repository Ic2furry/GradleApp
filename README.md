Minecraft Gradle Builder
Небольшое настольное приложение (Tkinter) для упрощённой сборки Minecraft-модов через Gradle. Позволяет выбирать JDK из встроенной папки, запускать gradlew/gradle с настраиваемыми аргументами и просматривать лог сборки в реальном времени. Поддержка светлой и тёмной темы; настройки сохраняются в config.json.
Функции
•	Выбор Gradle-проекта и JDK (скопировать JDK в ./java).
•	Запуск задач Gradle (набор предустановленных задач + свои аргументы).
•	Установка JAVA_HOME и аргументов Java для процесса сборки.
•	Просмотр и очистка логов в реальном времени.
•	Переключение темы интерфейса.
•	Сохранение настроек в config.json.
Требования
•	Python 3.8+
•	Tkinter
•	Gradle или gradlew в проекте
•	JDK (можно скопировать в папку java/ проекта)
Быстрый старт
1.	Поместить JDK(и) в папку java/ или добавить через интерфейс.
2.	Запустить: python builder.py
3.	Выбрать папку проекта, JDK, задать задачу и нажать "СБОРКА".
Конфигурация
•	config.json создаётся автоматически и хранит: project, java (путь), task, extra_args, java_args, theme.
